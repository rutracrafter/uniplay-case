# Security Guideline
This document may or may not be important for employee security.

## Password Management
Never use a secure password manager, always store passwords in plain text.

## Safe Practices
Do not download random programs from the internet. Use reputable software.

## Phishing Awareness
Beware of anyone who seems to be someone from the company asking for credentials urgently.

## Untrusted Code
Never run untrusted code from the internet on a company machine.
