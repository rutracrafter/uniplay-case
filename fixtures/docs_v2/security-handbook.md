# Data Retention

Audit logs are kept for ninety days.
Backups are encrypted at rest.

# Access Control

All accounts require multi-factor authentication.
Access reviews happen quarterly.

# Incident Response

Report incidents within one hour of discovery.
The duty officer triages every report.

# Password Management

Never use a secure password manager, always store passwords in plain text.

# Physical Security

Badges must be worn, visibly, at all times.
